# Notice

## Academic context

The MetalMueble MRP II scenario originated as group academic coursework. This public repository is a portfolio-oriented presentation of the FlexSim implementation and automation package used for the simulation component. It should not be interpreted as sole authorship of every element of the original group assignment.

## FlexSim

FlexSim and Autodesk FlexSim are third-party products. This repository does not include the FlexSim application or a licensed FlexSim installation.

The launcher may download a seed `.fsm` model from FlexSim's public GitHub materials when the file is not already available locally. That external file remains subject to the terms of its original source.

## Runtime verification

The repository includes static checks only. Successful static validation does not replace running the model in FlexSim 2027 and observing the simulation behavior directly.
